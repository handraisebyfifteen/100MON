# Friction Log — 100MON

## Testing on a physical Vega OS device

**Task attempted:** Test 100MON on a physical Vega OS Fire TV device.

**Steps taken:** Built the app with the Vega SDK and developed it using the Vega OS simulator. I looked for a way to run it on real Vega OS hardware, but I did not have access to a Vega OS device.

**Expected vs. actual result:** I expected to verify the app on a physical Vega OS device before submission. In practice, all Vega OS testing was done in the simulator. The simulator itself worked smoothly and I had no problems with it, but I could not confirm real-device behavior such as remote control responsiveness and performance on Vega OS hardware.

**Severity:** Medium

**Workaround:** Developed and tested on the Vega OS simulator, and confirmed the app runs correctly on a physical Fire OS Fire TV device.

**Actionable suggestion:** Offer a device loaner program or remote device testing for hackathon participants, so developers can confirm behavior on real Vega OS hardware. A short guide on known differences between the simulator and real devices would also help.
