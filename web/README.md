# ブラウザ版プロトタイプ

設計書 §15 の第2週ぶん。見え方の確認と、表示速度・基準時間の実測に使う。

## 動かし方

```
npm install     # 初回だけ
npm run dev     # http://localhost:5000 （Replit では Run ボタン）
```

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発用に起動する。ファイルを直すとすぐ反映される |
| `npm run build` | 公開用のファイルを `web/dist` に作る |
| `npm test` | `/core` の単体テスト |
| `npm run typecheck` | 型チェック |
| `npm run sfx` | 効果音の音声ファイルを作り直す |

## 操作

| 操作 | キーボード | 画面を押す場合 |
|---|---|---|
| 選ぶ | 矢印キー | 選択肢を押す |
| 確定 | Enter / Space | もう一度同じ選択肢を押す、または中央の OK |
| 中断してタイトルへ | Esc / Backspace | — |
| 設定を変える | タイトルの「設定」→ 上下で選び、左右で変える | 行の ◀▶ を押す |

選択肢の並びと方向の対応は 上・左・右・下 の順（`core/src/directions.ts` の1行で変えられる）。

## URL の末尾に付ける指定

| 指定 | 内容 |
|---|---|
| `?demo=1` | 入力なしで問題が流れ続ける。TV での見え方の確認用。記録には残さない |
| `?lang=en` | 言語（`ja` / `en`） |
| `?ms=120` | 表示速度。1文字あたりのミリ秒（20〜400） |
| `?window=2.5` | 回答の猶予（秒）。激ムズウィークの値を試すとき |
| `?n=10` | 先頭の n 問だけで走る。お試し用で、記録には残さない |
| `?seed=1` | 出題順を固定する |
| `?debug=1` | 受け取ったキー・画面サイズ・描画の速さを左下に出す |

組み合わせる場合は `&` でつなぐ（例：`?demo=1&lang=en&ms=60`）。

## 実測のしかた

- 表示速度：タイトルの「設定」にある「文字の速さ」を ◀▶ で変える（言語ごとに覚える）。下の行に、一番長い問題文の表示時間と、全問時間切れのときのタイムが出る
- 基準時間：同じ速さで何回か走ると、「記録」に**タイムの中央値**が出る
- 走行の生データ（1問ごとの回答・経過時間・設定）は、ブラウザの `localStorage` の `qth.runs.v1` に入っている（最新100走行）

## 見た目

8 ビット時代のゲーム機の作法に寄せている（ドット文字、角を欠いた二重線の枠、目盛り式のゲージ、段階的な動き）。
特定の作品のキャラクター・ロゴ・画像・音は使っていない。記号（矢印・丸・バツ）は自前のドット絵、効果音も自前。

- 正誤の表示：答えた直後、4つの選択肢の真ん中に丸かバツを大きく出し、問題文の枠の中にも色を1回出す。
  正解は「大きく出て止まる」、不正解と時間切れは「左右に揺れる」。直前の判定は右上にも残る
- 枠タイマー：4辺の棒を目盛りに区切ったゲージ。目盛り1つぶんずつ減る
- 走り出す前に「READY」を約1.2秒出す。この間はタイムに含めず、選択肢も見せない（`web/src/App.tsx` の `READY_MS`。0 で無効）
- 問題文と選択肢だけ通常の書体に戻したい場合は、`web/src/styles.css` の `--font-question` を書き換える

### 効果音

8 ビット時代のゲーム機の音源（矩形波2つ・三角波・ノイズ）に寄せた自前の音。
音声ファイルは `web/public/sfx/*.wav` にあり、`tools/make-sfx.mjs` に書いた音符から `npm run sfx` で作り直せる。

タイトルの「設定」で、全体のオン・オフと、下の1つずつのオン・オフを切り替えられる（端末に保存する）。
1つずつの行をオンにすると、その音が鳴る。

| 名前 | 鳴る場面 |
|---|---|
| `cursor` カーソル移動 | タイトル・設定で、選んでいる行を上下に動かしたとき |
| `change` 設定の変更 | 設定で、言語・文字の速さ・効果音全体を変えたとき |
| `decide` 決定 | タイトルで「記録」「設定」を開いたとき |
| `back` 戻る・中断 | 記録・設定・結果からタイトルへ戻るとき、走行を中断したとき |
| `ready` スタートの合図 | 走り出す前の「READY」 |
| `type` 文字送り | 問題文の文字が出るたび（速い設定では間引く） |
| `select` 選択肢をえらぶ | 選択肢を選んだ・選び直したとき |
| `urgent` 残り時間わずか | 枠タイマーの色が変わるとき（残り1.5秒） |
| `correct` 正解 | 確定して正解だったとき |
| `wrong` 不正解 | 確定して不正解だったとき |
| `timeout` 時間切れ | 答えないまま時間が切れたとき |
| `finish` 結果 | 結果画面が出るとき |
| `newBest` 自己ベスト更新 | 結果画面で自己ベストを更新したとき（`finish` の代わりに鳴る） |

ブラウザの決まりで、最初にキーか画面を押すまでは音が出ない（`?demo=1` は何か押すまで無音）。

## 構成

```
/core/src   ゲームの中身。画面にも時計にも依存しない（Vega 版でもそのまま使う）
/web/src    画面。/core に時刻と入力を渡し、返ってきた状態を描くだけ
/data       問題セットとピリオド（読み込むファイルは web/src/data.ts で指定）
```

暫定の設定値（表示速度・回答の猶予・基準時間・確定直後に入力を受け付けない時間）は
`core/src/settings.ts` の `DEFAULT_CONFIG` にまとめてある。

## まだ無いもの

- ランキング、ポイント、連続プレイ日数（バックエンドができてから）
- 激ムズウィークの挑戦回数の制限（サーバー側で判定する設計のため）
- 走行の開始・終了時刻はブラウザの時計。本番ではサーバー時刻に置き換える
